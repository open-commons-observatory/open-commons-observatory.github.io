# The observatory's own design, as data

Everything the observatory is - its concepts, the decisions taken and why (with what was rejected),
its backlog and its session log - is kept here as tad data (text as data: one JSON object per line),
so nothing depends on anyone remembering. The observatory harvests these tables like any project's.

The practices - how agents and people work in the ecosystem - were kept here until 2026-11-17. They are now
kept in grenudi/ideal-agent (`data/practices.json`, entered with `tad r practice`), the one home of general
agent know-how; the observatory still shows them, as ideal-agent's rows (decision
2026-11-17-practices-kept-in-ideal-agent).
